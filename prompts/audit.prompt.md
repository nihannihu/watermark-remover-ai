# Audit Prompt

Review the repository and report:

1. Architecture and module boundaries
2. Security-sensitive paths
3. Test coverage gaps
4. Dependency and compatibility risks
5. Likely regression points
6. Recommended safe next steps

Use the repository as the source of truth. Prefer concrete findings with evidence.
