# Production Readiness Prompt

Perform a production-readiness review across:

- correctness
- reliability
- security
- performance
- maintainability
- setup and deployment assumptions
- error handling
- testing evidence
- user-facing behavior

State what is verified, what is assumed, and what remains risky or unvalidated.
